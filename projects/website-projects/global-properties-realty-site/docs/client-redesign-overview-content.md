# Global Properties Realty Website Redesign

Prepared for: Global Properties Realty, LLC  
Prepared by: Demilade Creatives  
Date: June 30, 2026

## Project Overview

The goal of this project is to give Global Properties Realty a professional, modern, and mobile-friendly website that presents its services clearly and makes it easier for clients to contact the brokerage and begin the rental-application process.

The redesigned website will provide clearer paths for buyers, sellers, property owners, tenants, commercial clients, and other priority audiences.

## Project Investment

**Total fixed project price: $2,500**

Payment schedule:

- $1,250 to schedule and begin the project.

- $625 after final approval and before the website launches.

Domain registration, hosting, Formsite, Resident Research, payment-processing charges, premium software, and other third-party costs are separate. No additional purchase will be made without client approval.

## Services Included

### Planning and Design

- Review the current website, content, navigation, and client experience.
- Improve the organization of the website and its services.
- Create a modern visual design consistent with the Global Properties Realty brand.
- Design the website for desktop computers, tablets, and mobile phones.

### Website Development

- Build up to 10 primary pages or equivalent page layouts.
- Anticipated pages include Home, About, Buying, Selling, Commercial Real Estate, REO/Bank-Owned Properties, Property Management, Rental Application, Contact, and Privacy.
- Add clear options to call, text, email, request information, and begin a rental application.
- Add standard contact and property-inquiry forms with spam protection.
- Remove confusing or unnecessary public website elements.
- Lightly edit existing content for grammar, clarity, and consistency.

### Rental Application Improvements

- Create a clear, mobile-friendly introduction to the rental application.
- Explain the application process, fees, estimated completion time, and support contacts using client-approved information.
- Reconnect or re-embed the existing Formsite/Resident Research application when account access and provider settings allow.
- Provide a direct application link as a backup when appropriate.
- Test the application entry point on mobile and desktop devices.

Formsite, Resident Research, and the connected payment provider will continue handling application fees, consent, screening, and sensitive applicant information. Building a new background-screening, payment, or applicant-record system is not included.

### Search, Testing, and Launch

- Configure basic page titles, descriptions, social-sharing information, and local-business details.
- Add analytics using a client-owned account if available.
- Optimize supplied images and website files for reasonable performance.
- Test navigation, links, inquiry forms, accessibility basics, and common screen sizes.
- Connect the approved domain to the new website.
- Configure HTTPS and important redirects where access and technical conditions allow.
- Provide two consolidated revision rounds.
- Provide 30 days of post-launch support for defects within the agreed project scope.

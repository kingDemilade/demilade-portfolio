## Services Included

### Planning and Design

- Review the existing website, content, navigation, and client experience.
- Organize the website around buyers, sellers, property owners, tenants, commercial clients, and other priority audiences.
- Create a modern visual design consistent with the Global Properties Realty brand.
- Design the website for desktop computers, tablets, and mobile phones.

### Website Development

- Build up to 10 primary pages or equivalent page layouts.
- Anticipated pages include Home, About, Buying, Selling, Commercial Real Estate, REO/Bank-Owned Properties, Property Management, Rental Application, Contact, and Privacy.
- Add clear options to call, text, email, request information, and begin a rental application.
- Add standard contact and property-inquiry forms with spam protection.
- Correct distracting or unnecessary public website elements such as the current login box, article details, hit counters, and confusing page structure.
- Lightly edit existing text for grammar, clarity, and consistency.

### Rental Application Improvements

- Create a clear, mobile-friendly introduction to the rental application.
- Explain the application process, fees, estimated completion time, and support contacts using client-approved information.
- Reconnect or re-embed the existing Formsite/Resident Research application when account access and provider settings allow.
- Provide a direct application link as a backup if the embedded application cannot load properly.
- Test the application entry point and page behavior on mobile and desktop devices.

Formsite, Resident Research, and the connected payment provider will remain responsible for collecting application fees, consent, screening information, and sensitive applicant data. Building a new background-screening, payment, or applicant-record system is not included.

### Search, Performance, and Launch

- Configure basic page titles, descriptions, social-sharing information, and local-business details.
- Add analytics using a client-owned account if one is available.
- Optimize supplied images and frontend files for reasonable website performance.
- Test navigation, links, inquiry forms, accessibility basics, and common browser sizes.
- Connect the approved domain to the new Netlify website.
- Configure HTTPS and important redirects where access and technical conditions allow.
- Provide two consolidated revision rounds.
- Provide 30 days of post-launch support for defects within the agreed project scope.
